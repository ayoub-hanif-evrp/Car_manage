# Darija navigation clips — owner checklist

Record short MP3 clips (mono, ~16–32 kbps recommended for the Galaxy A02) and place them in `assets/audio/darija/`.

| File name | Suggested wording |
|---|---|
| `continue_straight.mp3` | بقا نيشان |
| `turn_left.mp3` | دور على ليسر |
| `turn_right.mp3` | دور على ليمن |
| `in_100_m.mp3` | من بعد مية متر |
| `in_200_m.mp3` | من بعد ميتين متر |
| `in_500_m.mp3` | من بعد خمسمية متر |
| `roundabout_exit_1.mp3` | فالرومبوان، خود الخرجة اللولة |
| `roundabout_exit_2.mp3` | فالرومبوان، خود الخرجة الثانية |
| `roundabout_exit_3.mp3` | فالرومبوان، خود الخرجة التالتة |
| `recalculate.mp3` | عاودنا حسبنا الطريق |
| `arrived.mp3` | وصلتي للوجهة ديالك |

Do **not** claim Darija voice is complete until these files exist and playback is tested on the Galaxy A02 during real navigation events.

French fallback for unsupported maneuvers is only used if a verified navigation SDK is active and permits it.
